# UI/UX Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the 54 findings from the 2026-09-17 UI/UX audit so the platform behaves like a product: it speaks the user's language, confirms what it does, fails legibly, and can be operated without a mouse.

**Architecture:** The UI is metadata-driven, so most fixes land in one shared place and reach all 31 tables: display labels come from `/api/meta/schema`, feedback from one toast provider, formatting from `DataTable`, validation from `EntityForm`. The graph editor is fixed in its own components. Tasks are ordered by severity so that stopping early still leaves the worst problems fixed.

**Tech Stack:** FastAPI + SQLAlchemy 2 + Pydantic v2; React 18 + TypeScript + Vite + React Query + React Router 6 (`BrowserRouter`) + Tailwind 3; Cytoscape.js; pytest; Vitest + React Testing Library; Docker Compose.

**Spec:** docs/superpowers/specs/2026-09-17-ux-fixes-design.md

## Global Constraints

- Baseline to keep green: **backend 107 tests, frontend 146 tests**, `npm run build` clean. Every task runs both suites before committing.
- Frontend test conventions: `vi.mock("../api/client", async () => {...})` keeping `getToken`/`setToken` real; cytoscape/elk/edgehandles mocked via the existing `vi.hoisted()` pattern in `GraphEditor.test.tsx`; never render a real canvas in jsdom.
- Backend test conventions: unique values suffixed with `uuid.uuid4().hex[:8]`; tests run against the isolated `solver_test` database via `backend/tests/conftest.py` — never against the app database.
- Do **not** change `backend/app/graph/schemas.py` or `frontend/src/types/graph.ts` (the hand-synced graph contract). Extending `/api/meta/schema` and `frontend/src/types/meta.ts` together is expected and fine.
- Neither Docker image has a bind mount. Before any live/browser check: `bash scripts/rebuild.sh`.
- No new npm or pip dependencies. Toasts, skeletons and focus management are hand-rolled.
- `useBlocker` requires a data router; this app uses `BrowserRouter`, so the unsaved-changes guard is `beforeunload` plus a guard consulted by the shell's own navigation (Task 5). Do not migrate the router.
- Audit finding IDs (`A-1 … H-12`) are referenced per task; they come from the audit report and are the acceptance criteria.
